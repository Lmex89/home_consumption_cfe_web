# UI en español, código en inglés

La interfaz de usuario está completamente en español (etiquetas, mensajes de error, textos de botones), pero el código fuente usa nombres en inglés para variables, funciones y componentes (`householdId`, `billingPeriod`, `fetchBillingPeriods`, `DashboardPageContainer`).

Esto es deliberado. El código en inglés sigue la convención estándar de la industria (la mayoría de documentación, librerías y herramientas están en inglés), lo que facilita la búsqueda de soluciones y la colaboración con desarrolladores que no hablen español. La UI en español refleja la audiencia objetivo: usuarios mexicanos que gestionan su consumo de CFE.

El glosario del frontend documenta los términos de UI en español y su correspondencia con los conceptos del dominio (que están en el glosario del backend, también en español).
